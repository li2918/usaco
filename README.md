# USACO 新学员能力评估系统

这是一个纯前端的 USACO 入班诊断原型，用于评估新学员在基础编程、Bronze、Silver、Gold 相关能力上的当前水平。

## 功能

- 学员信息记录：姓名、语言、学习目标
- 45 分钟限时测评
- 18 道分层选择题，覆盖基础实现、模拟、枚举、贪心、前缀和、二分、图论、动态规划和数据结构
- 自动判分并估计推荐班型
- 按知识点输出能力雷达、诊断结论和学习路径建议
- 支持打印测评报告

## 使用方式

直接在浏览器中打开 `index.html` 即可使用，无需安装依赖。

## 后续可扩展方向

- 接入后端保存学员历史测评记录
- 将选择题升级为代码题，并接入沙箱或 Online Judge 判题
- 增加自适应出题：根据前 6 题表现动态选择 Bronze、Silver 或 Gold 题组
- 为教师端增加班级看板、短板分布和升班建议
