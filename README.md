# USACO 新学员能力评估系统

这是一个纯前端 USACO 入班诊断系统，用于评估新学员在基础编程、Bronze、Silver、Gold 相关能力上的真实水平。

## 功能

- 单题作答流程，不再把所有题目铺在一个页面上
- 60 分钟限时测评
- 12 道分层题，包含选择题、简答题和代码题
- Bronze/Silver/Gold 代码题覆盖枚举、图论、树状数组/线段树、双指针等能力
- 自动初评客观题、简答题关键点和代码题结构
- 报告输出推荐班型、能力雷达、诊断结论、代码题复核清单和学习路径
- 支持打印测评报告

## 使用方式

直接在浏览器中打开 `index.html` 即可使用，无需安装依赖。

## 评分说明

选择题会按标准答案自动判分。简答题会根据表达长度和关键概念自动初评。代码题会根据实现线索、复杂度说明和核心结构自动给出初评分数，并在报告里展示老师复核清单。

当前版本适合作为入班筛查原型；正式用于教学前，建议老师对代码题进行人工复核。

## 后续可扩展方向

- 接入后端保存学员历史测评记录
- 将代码题接入沙箱或 Online Judge，实现样例与隐藏测试点判题
- 增加自适应出题：根据前几题表现动态选择 Bronze、Silver 或 Gold 路线
- 为教师端增加班级看板、短板分布和升班建议
